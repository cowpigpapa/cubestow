    안내

    Cubestow 사용 가이드

    제품 등록부터 3D 적재안 확인과 프로젝트 저장까지 한 화면에서 진행할 수 있습니다.

    STEP 01제품 등록직접 입력하거나 Excel·CSV 파일을 불러옵니다.
    STEP 02조건 선택안전 수준·배치 방식·운송 경로·고정재와 컨테이너를 고릅니다.
    STEP 03결과 확인3D 배치, 적재 순서와 고정재 권고를 검토합니다.
    STEP 04저장·내보내기프로젝트를 저장하거나 PDF 작업지시서·Excel 계획을 내려받습니다.
    1. 제품 입력
    • 직접 입력에서는 제품명, 형상, 수량, 길이·너비·높이와 개당 중량을 입력합니다.
    • 여러 제품은 Excel 또는 CSV로 한 번에 등록할 수 있습니다.
    • 눕힘 허용은 높이 축 변경을 허용하며, 상부 적재 금지는 해당 화물 위의 배치를 막습니다.
    • 제품 데이터 제목 옆 "접기" 버튼으로 입력칸을 접을 수 있고, 넓은 화면에서는 왼쪽 칸과 3D 사이의 손잡이(‹)로 왼쪽 칸 전체를 숨겨 3D를 크게 볼 수 있습니다.
    2. 선택 항목의 뜻
    • 안전 수준(슬라이더) — 어떤 규칙을 반드시 지킬지: 왼쪽으로 갈수록 많이 싣고, 오른쪽으로 갈수록 안전 조건이 늘어납니다. 적재량 우선은 윗 화물 바닥면 70% 이상만 받치면 되고 충돌·하중 같은 기본 조건만 지킵니다. 최대한 많이 싣되, 같은 양이면 높은 탑이나 얹힘처럼 위험해 보이는 자리는 피합니다(위험 판단은 사용자 몫). 기본(권장)은 100% 받침, 가느다란 화물 위 적재 금지(같은 규격 드럼은 2단까지), 원통은 바닥이나 원통 위에만, 높은 적층 전도 방지를 지키고 남는 틈과 윗단은 고정재(에어백·래싱 등)로 막습니다. CTU 기준 적용는 기본에 더해 모든 화물의 안쪽·좌·우를 화물이나 벽으로 막고, 다른 크기 화물 위에 따로 얹지 않습니다. 화물끼리 막는 배치가 컨테이너를 더 쓰면 기본 배치를 쓰고, 화물로 막히지 않은 면은 에어백·충전재·래싱으로 막도록 고정재 권고에 화물별로 적습니다(CTU Code는 화물 외 고정재로 막는 것도 인정). 래싱을 끄면 CTU 전도 기준을 모든 화물에 적용합니다.
    • 배치 방식 — 같은 대수의 결과 중 무엇을 고를지: 대수와 미적재는 항상 먼저 줄이고, 그 결과들이 같을 때만 적용합니다. 휴리스틱이라 정답이 하나가 아니므로 목적에 맞게 고릅니다. 추천은 무게배분 사전검사 등급 → 좌우·앞뒤 편차 → 운송 안정성 순으로 고릅니다. 붙여 싣기는 화물을 안쪽으로 바짝 붙여 사용 길이가 가장 짧은 배치(빈틈과 고정재가 가장 적음)를 고릅니다. 무게중심은 앞뒤·좌우 편차가 가장 작은 배치를 고릅니다(무게중심을 맞추려고 화물 사이를 벌릴 수 있고, 벌린 만큼 에어백·래싱이 늘어납니다).
    • 운송 경로 — 어떤 힘을 견뎌야 하는지: 안전 수준이 "규칙의 수준"이라면 운송 경로는 "받는 힘"입니다. CTU Code 가속도(육상: 좌우 0.5g·전방 0.8g·후방 0.5g, 해상 C: 좌우 0.8g·앞뒤 0.4g)에 따라 측면 지지 판정, 전도 한계, 래싱 수가 바뀝니다. 복합은 육상과 해상 중 불리한 값을 씁니다.
    • 고정재(칩): 에어백·충전재·바닥 못·래싱 칩을 눌러 켜고 끕니다. 끈 고정재는 다른 방법으로 대신하고, CTU 기준 적용에서 래싱을 끄면 막힘만으로 넘어지지 않게 배치합니다.
    • 20ft, 40ft, 40ft High Cube, 45ft High Cube를 지원합니다. 도로로 나가는 컨테이너는 "한국 도로 한도" 항목(20ft 21t, 40ft 25t)을 고르면 도로법 중량 기준으로 대수를 나눕니다.
    3. 배치 방식(선적 방법)과 추천 방법
    • 한 번 실행할 때 아래 배치 방식을 투입 순서 4가지(부피 큰 순·가장 긴 변 순·바닥면 큰 순·무거운 순)와 조합해 여러 배치안을 만들고, 컨테이너마다 가장 좋은 안을 고릅니다. 화물이 남거나 무게배분이 위험하면 제품 순서를 섞은 배치안을 더 계산합니다(순서는 고정이라 같은 입력이면 결과가 같습니다).
    • 같은 규격 기둥 쌓기: 같은 제품을 같은 방향으로 수직으로 쌓아 안쪽부터 세웁니다. 반복 규격이 많을 때 유리합니다.
    • 균형 기둥 쌓기: 기둥 쌓기와 같되, 무게중심이 가운데에 오도록 제품 그룹 순서를 정하고 기둥을 낮춰 종방향으로 펼칩니다.
    • 바닥 우선(DBLF): 바닥을 먼저 안쪽·왼쪽부터 채우고 그 위에 쌓습니다.
    • 공간 집약: 높이 방향까지 빈 곳을 가장 촘촘히 채웁니다.
    • 폭 채움: 한 줄의 폭을 꽉 채워 화물이 옆으로 서로 기대도록 합니다.
    • 무게중심 배치: 놓을 때마다 무게중심이 가운데에 가까운 자리를 고릅니다.
    • 벽 쌓기 · 전폭 벽(스트립)(CTU 기준 적용 전용): 폭 전체를 채우는 층을 안쪽부터 한 층씩 세웁니다. 스트립은 같은 높이의 기둥들로 벽을 만들어 3면이 서로 막히게 합니다.
    • 배치 후에는 서로 걸치지 않는 구간의 순서를 바꾸거나 좌우·앞뒤로 뒤집어 무게중심을 맞추고, 큰 화물이 안쪽에 오도록 합니다. 마지막으로 화물 묶음을 안쪽 벽으로 밀어 빈틈을 문쪽에 모읍니다(문쪽 틈은 각재·펜스로 막음).
    • 마지막 컨테이너에 화물이 조금만 남아 무게중심이 안쪽으로 쏠리면(무게배분 위험), 앞 컨테이너와 화물을 반씩 다시 나눕니다.
    • 케이블 드럼처럼 무거운 화물(개당 1t 이상, 원통 500kg 이상)은 무게중심이 가운데에 오도록 컨테이너 가운데에 싣고, 양 끝을 못 박은 바닥 각재·쐐기로 막습니다. 바닥 1m당 하중이 한계(20ft 4.5t, 40ft 3.0t)를 넘으면 받침목을 안내합니다.
    • CTU 기준 적용에서는 남은 화물을 한 번 더 채워 넣고, 그래도 컨테이너가 늘면 기본 배치를 쓰되 화물로 막히지 않은 면을 고정재로 막도록 안내합니다.
    • 추천: 컨테이너마다 ① 실린 부피 ② 실린 수량 ③ 우선 기준 순으로 가장 좋은 안을 씁니다. 같은 입력이면 어느 컴퓨터에서나 같은 결과가 나옵니다.
    4. 시뮬레이션 결과 확인
    • 3D와 상면 보기로 배치를 확인하고 단계 재생으로 실제 적재 순서를 검토합니다.
    • 여러 컨테이너가 필요하면 화살표로 각 컨테이너 결과를 이동합니다.
    • 각재·부목과 에어백 표시는 화면에서 켜고 끌 수 있습니다.
    • 운송모드별 높은 적층·측면 간극·문측 노출·원통 구름 위험은 구체적인 검토 사유로 표시합니다.
    • CTU 기준 적용에서 화물로 막히지 않은 면은 고정재 권고의 "CTU 열린 면 보강"에 화물 번호·면·방법(래싱 또는 에어백·충전재)으로 나옵니다.
    • 미배치 화물은 제품별 사유(공간·지지 부족, 중량 초과, 최대 50대 초과, 고정재 부족 등)와 함께 표시합니다.
    • 결과 요약 아래 자동 평가는 규칙으로 결과를 점검해(AI 아님) 양호·주의·재검토 필요 등급과 항목별 지적·고칠 방법을 보여 줍니다. 무게배분, 첫 화물 밀착, 얹힘, 높은 적층, 안쪽 빈 곳, 중간 충전재, 에어백 개수, 바닥 선하중, 마지막 컨테이너 소량을 봅니다. 알고리즘이 잘못했을 수 있는 결과는 개선을 위해 관리자 점검 기록으로 남깁니다(입력 제품·조건만, 관리자만 열람).
    5. 프로젝트 저장
    • 비로그인 상태에서는 현재 브라우저에, 로그인 상태에서는 계정별 클라우드에 저장됩니다.
    • 저장 목록에서 프로젝트를 불러오면 저장된 조건으로 시뮬레이션이 자동 실행됩니다.
    • 미배치 화물이 있으면 안전 검토를 위해 PDF·Excel 내보내기가 제한됩니다.
    • PDF·Excel을 내보내기 전에 현장 확인이 필요한 검토용 문서라는 안내를 한 번 확인합니다.
    현장 확인 필수결과는 작업 검토용 제안입니다. 실제 상차 전 화물 강도, 중량중심, 운송 조건과 고정재 지침을 확인하세요.

      현재 계산 로직
      1. 입력 데이터를 공통 제품 모델로 정규화하고 부피·중량으로 필요한 컨테이너 대수의 하한을 계산합니다.
      2. 허용 회전과 Extreme Point 후보를 만들고, 후보를 아래·안쪽·좌측으로 밀착시킵니다.
      3. 경계·충돌·중량·상부 금지·지지율·중심 지지·측면 지지·상부 허용하중·스택 합성 무게중심을 검사합니다. 하나라도 통과하지 못하면 배치하지 않습니다. 측면 지지는 적재를 마친 최종 상태에서 다시 확인합니다. CTU 기준 적용은 모든 화물의 안쪽·좌·우 3면이 막혀야 하고(문쪽은 각재로 막음) 다른 크기 화물 위 얹힘을 금지합니다. 먼저 화물끼리 막히는 배치를 찾고, 그 때문에 컨테이너가 늘면 기본 배치를 쓰되 화물로 막히지 않은 면을 에어백·충전재·래싱으로 막도록 안내합니다. 래싱을 쓰지 않으면 CTU 전도 기준을 모든 화물에 적용합니다. 적재량 우선은 적재량을 우선합니다.
      4. 배치 규칙 6종(같은 규격 기둥 쌓기, 균형 기둥 쌓기, 바닥 우선, 공간 집약, 폭 채움, 무게중심)과 투입 순서 4종을 계산하고, CTU 기준은 벽 쌓기·전폭 벽을 더합니다. 화물이 남거나 무게배분이 위험하면 제품 순서를 고정 시드로 섞은 순서 24종을 예산 안에서 더 계산합니다. 전부 싣고 무게배분이 양호한 안이 나오면 계산을 일찍 마칩니다.
      5. 컨테이너마다 적재 부피가 가장 큰 결과를 고르고, 같으면 우선 기준으로 고릅니다. 남은 화물은 다음 컨테이너에서 같은 방식으로 계산합니다. 첫 적재는 예외 없이 안쪽 벽에 붙입니다. 서로 걸치지 않는 구간(슬라이스)은 순서를 바꾸거나 좌우·앞뒤로 뒤집어 무게중심을 가운데로 맞추고, 고른 안은 화물 묶음을 안쪽 벽으로 밀어 빈틈을 문쪽에 모읍니다. 가벼운 마지막 컨테이너가 무게배분 위험이면 앞 컨테이너와 화물을 반씩 다시 나눕니다. 남는 쏠림은 사전검사 경고로 알립니다.
      6. 후보 비교는 가중치 합산이 아니라 항목별 순서 비교로 하며, 결과는 생성 엔진과 분리된 validator로 다시 검사합니다.
      7. 이전 결과가 한 대로 완료됐고 조건이 같으면, 유효한 기존 배치를 유지하고 바뀐 화물만 다시 배치합니다.
      절대 우회하지 않는 안전 조건
      • 컨테이너 경계, 제품 충돌과 최대 중량 준수
      • 상부 적재 금지 화물 위 배치 금지
      • 상부 화물 중심이 실제 지지 영역 안에 존재
      • 원통 위 박스 금지, 원통 적층 정렬 조건 적용
      • 첫 화물은 예외 없이 컨테이너 안쪽 벽에 밀착
      • 입력 수량 = 적재 수량 + 미배치 수량
      운송모드별 안정성 기준
      • 해상은 피칭·롤링·히빙을 고려해 높은 적층과 측면 지지를 가장 보수적으로 선별합니다.
      • 복합운송은 해상과 육상 구간을 함께 고려하는 기본 권장값입니다.
      • 육상은 동일 위험을 검사하되 높이와 측면 지지 임계값을 일부 완화합니다.
      • 래싱은 위치와 줄 수(빠른 래싱 가이드 C 표, 고른 마찰·래싱 MSL·고정점 기준)를 권고하고, 3D 경로·각도·STF는 계산하지 않습니다. 재배치 또는 현장 고정이 필요한 이유를 함께 표시합니다.
      CTU Code 반영 범위
      • CTU Code(IMO·ILO·UNECE 화물운송단위 적입 실무규칙)를 모든 기준값의 기본으로 삼고, CTU가 정하지 않은 값은 제조사 값 또는 Cubestow 설정으로 구분해 표시합니다(알고리즘 정책 문서 5장).
      • 경계·충돌·중량·지지·미배치 검증과 3축 무게중심, 중심 편차, 수직 무게중심, 50% 길이 구간의 최대 질량 집중도를 제공합니다.
      • 상부 허용하중이 입력된 제품은 상부 화물의 누적하중을 검사하고, 미입력 제품은 미검증으로 구분합니다.
      • 운송 경로별 가속도 계수(CTU Code 5장·정보자료 IM5)로 막히지 않은 방향의 미끄럼 억제력과 전도 위험을 참고 계산합니다. 마찰계수는 고정 조건에서 고르고(확인하지 못했으면 0.3), 문은 막힌 경계로 보지 않습니다.
      • 해상·복합·육상 운송별로 높은 적층, 측면 간극, 문측 노출과 원통 구름 위험을 선별합니다.
      • 에어백(제조사 최대 간극 500mm)·충전재·바닥 각재(못 1개 1kN으로 못 수 계산)·도어 스트랩·윗단 되잡기 래싱을 권고하고, 래싱 줄 수는 빠른 래싱 가이드 C 표와 고른 고정 조건(마찰·래싱 MSL·고정점)으로 계산합니다.
      • 안전 수준 "CTU 기준 적용"은 모든 화물의 안쪽·좌·우를 화물이나 고정재로 막고 얹힘을 금지한 배치를 만듭니다(3면 막힘·얹힘 금지·전도 한계).
      • 결과는 CTU Code 기반 사전 검토 자료이며 적합성 인증이나 현장 책임자의 승인을 대신하지 않습니다.
      현재 계산하지 않는 한계

      • 모든 조합을 탐색하는 전역 최적화
