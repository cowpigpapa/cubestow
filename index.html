    USER GUIDE

    Cubestow 사용 가이드

    제품 등록부터 3D 적재안 확인과 프로젝트 저장까지 한 화면에서 진행할 수 있습니다.

    STEP 01제품 등록직접 입력하거나 Excel·CSV 파일을 불러옵니다.
    STEP 02조건 선택컨테이너 규격, 안전 기준과 우선 기준을 선택합니다.
    STEP 03결과 확인3D 배치, 적재 순서와 고정재 권고를 검토합니다.
    STEP 04저장·내보내기프로젝트를 저장하거나 Excel 계획을 내려받습니다.
    1. 제품 입력
    • 직접 입력에서는 제품명, 형상, 수량, 길이·너비·높이와 개당 중량을 입력합니다.
    • 여러 제품은 Excel 또는 CSV로 한 번에 등록할 수 있습니다.
    • 눕힘 허용은 높이 축 변경을 허용하며, 상부 적재 금지는 해당 화물 위의 배치를 막습니다.
    2. 컨테이너와 적재 기준
    • 20ft, 40ft, 40ft High Cube, 45ft High Cube를 지원합니다.
    • 안전 기준은 모든 배치가 반드시 지켜야 하는 조건입니다. 엄격은 상부 화물 바닥면을 100% 지지하고 세장 화물 위 적재를 막으며, 표준은 70% 이상 지지를 허용합니다.
    • 같은 안전 기준 안에서는 미배치 수량과 컨테이너 대수를 가장 먼저 줄입니다. 우선 기준은 대수가 같은 결과 중에서만 고릅니다.
    • 공간 활용은 사용 길이를, 폭 균형은 측면 지지와 운송 안정성 검토 건수를, 무게중심은 전후·좌우 편차를 먼저 줄입니다.
    • 자동 추천은 CTU 사전검사 등급, 운송 안정성 검토 건수, 중심 편차 순으로 고릅니다.
    3. 시뮬레이션 결과 확인
    • 3D와 상면 보기로 배치를 확인하고 단계 재생으로 실제 적재 순서를 검토합니다.
    • 여러 컨테이너가 필요하면 화살표로 각 컨테이너 결과를 이동합니다.
    • 각재·부목과 에어백 표시는 화면에서 켜고 끌 수 있습니다.
    • 운송모드별 높은 적층·측면 간극·문측 노출·원통 구름 위험은 구체적인 검토 사유로 표시합니다.
    4. 프로젝트 저장
    • 비로그인 상태에서는 현재 브라우저에, 로그인 상태에서는 계정별 클라우드에 저장됩니다.
    • 저장 목록에서 프로젝트를 불러오면 저장된 조건으로 시뮬레이션이 자동 실행됩니다.
    • 미배치 화물이 있으면 안전 검토를 위해 Excel 내보내기가 제한됩니다.
    현장 확인 필수결과는 작업 검토용 제안입니다. 실제 상차 전 화물 강도, 중량중심, 운송 조건과 고정재 지침을 확인하세요.

    알고리즘 정책과 한계

    Cubestow의 결과는 작업 검토를 위한 휴리스틱 제안이며 전역 최적해나 안전 인증을 의미하지 않습니다.

    안전 기준 · 엄격상부 지지 100%세장 화물 위 적재 금지·중심 지지
    안전 기준 · 표준상부 지지 70% 이상중심 지지·상부 금지 조건은 동일
    비교 순서미배치 → 대수같은 안전 기준 안에서 먼저 최소화
    우선 기준대수가 같을 때만자동 추천·공간 활용·폭 균형·무게중심
    계산 방식16개 후보 비교배치 규칙 4종 × 투입 순서 4종, 백그라운드 계산
    현재 계산 로직
    1. 입력 데이터를 공통 제품 모델로 정규화하고 부피·중량으로 필요한 컨테이너 대수의 하한을 계산합니다.
    2. 허용 회전과 Extreme Point 후보를 만들고, 후보를 아래·안쪽·좌측으로 밀착시킵니다.
    3. 경계·충돌·중량·상부 금지·지지율·중심 지지·측면 지지·상부 허용하중을 검사합니다. 하나라도 통과하지 못하면 배치하지 않습니다.
    4. 배치 규칙 4종(바닥 우선, 공간 집약, 폭 채움, 무게중심)과 투입 순서 4종을 모두 계산합니다.
    5. 컨테이너마다 적재 부피가 가장 큰 결과를 고르고, 같으면 우선 기준으로 고릅니다. 남은 화물은 다음 컨테이너에서 같은 방식으로 계산합니다.
    6. 후보 비교는 가중치 합산이 아니라 항목별 순서 비교로 하며, 결과는 생성 엔진과 분리된 validator로 다시 검사합니다.
    7. 이전 결과가 한 대로 완료됐고 조건이 같으면, 유효한 기존 배치를 유지하고 바뀐 화물만 다시 배치합니다.
    절대 우회하지 않는 안전 조건
    • 컨테이너 경계, 제품 충돌과 최대 중량 준수
    • 상부 적재 금지 화물 위 배치 금지
    • 상부 화물 중심이 실제 지지 영역 안에 존재
    • 원통 위 박스 금지, 원통 적층 정렬 조건 적용
    • 입력 수량 = 적재 수량 + 미배치 수량
    운송모드별 안정성 기준
    • 해상은 피칭·롤링·히빙을 고려해 높은 적층과 측면 지지를 가장 보수적으로 선별합니다.
    • 복합운송은 해상과 육상 구간을 함께 고려하는 기본 권장값입니다.
    • 육상은 동일 위험을 검사하되 높이와 측면 지지 임계값을 일부 완화합니다.
    • 자동 밴드 경로와 수량은 생성하지 않고, 재배치 또는 현장 고정이 필요한 이유만 표시합니다.
    CTU Code 반영 범위
    • CTU Code의 적입·고정 원칙을 정책과 향후 계산 구조의 기준으로 사용합니다.
    • 운송모드별 가속도, 미끄럼·전도 모멘트와 고정력 계산은 아직 구현 전입니다.
    • 본 결과는 CTU Code 적합성 인증이나 현장 책임자의 승인을 대신하지 않습니다.
    현재 계산하지 않는 한계
    • 허용하중 미입력 제품의 압축강도, 면압과 포장재 열화
    • 바닥 집중하중과 차량 축하중
    • 마찰·충격·진동, 래싱 LC/STF·각도·수량과 앵커 허용하중
    • 위험물 격리, 냉동 공기 순환과 법규 적합성
    • 모든 조합을 탐색하는 전역 최적화
    알고리즘 변경 원칙
    • 공통 안전 조건을 우회하지 않습니다.
    • 기존 전략과 같은 입력으로 결과를 비교합니다.
    • 경계·충돌·중량·지지 회귀 테스트를 통과해야 합니다.
    • 미배치와 실패 이유를 숨기지 않고 정책 버전과 변경 이력을 갱신합니다.
    현장 확인 필수실제 상차 전 화물 사양, 컨테이너 상태, 고정재 제조사 지침과 운송 규정을 확인하세요.
    CTU CODE GUIDE

    CTU Code란?

    IMO·ILO·UNECE가 공동 발행한 Cargo Transport Unit 포장·적입 실무 지침입니다. 컨테이너에 무엇을 얼마나 싣는지뿐 아니라 작업 준비, 중량 배분, 화물 고정과 운송 중 위험까지 다룹니다.

    BEFORE작업 전 확인컨테이너 상태·화물 정보·작업 계획 점검
    PACKING안전한 적입중량 분배·바닥 하중·빈 공간과 작업 동선 검토
    SECURING이동 방지블로킹·쇼어링·래싱·마찰을 조합해 검증
    AFTER출발 전 확인문 개방 위험·표시·서류·최종 상태 점검
    1. CTU Code의 성격
    • 정식 명칭은 IMO/ILO/UNECE Code of Practice for Packing of Cargo Transport Units입니다.
    • 전 세계 CTU 작업의 공통 실무 기준을 제시하지만 그 자체가 모든 국가에서 동일하게 강제되는 법률이나 인증서는 아닙니다.
    • 송하인, 포장 작업자, 운송인과 현장 책임자의 역할 및 정보 전달을 함께 다룹니다.
    2. 적입 전·중·후 핵심 확인
    • 적입 전에는 CTU의 구조 손상, 청결·건조 상태, 내부 돌출물과 문 작동 상태를 확인합니다.
    • 적입 중에는 총중량, 무게중심, 바닥 하중 분산, 화물 강도, 적재 순서와 작업자 안전을 검토합니다.
    • 적입 후에는 화물 이동과 문을 열 때 쏟아질 위험을 방지하고, 고정 상태와 필요한 표시·서류를 확인합니다.
    3. 고정의 기본 원칙
    • 화물 질량만으로 움직이지 않는다고 가정하지 않으며 마찰만을 단독 고정 수단으로 의존하지 않습니다.
    • 블로킹·쇼어링은 힘을 CTU 구조로 전달하고, 직접 래싱은 목표 방향에 저항하며, 톱오버 래싱은 추가 압력으로 마찰을 높입니다.
    • 원통과 구름 가능 화물은 초크·웨지·크래들 등 구름 방지 수단을 먼저 검토합니다.
    • 밴드, 앵커, 화물 고정점과 컨테이너 벽체는 각각의 허용하중을 확인해야 합니다.
    4. 운송 중 작용하는 힘
    • CTU Code는 화물 질량과 도로·철도·해상 조건별 가속도계수로 방향별 관성력을 검토합니다.
    • 미끄럼과 전도는 서로 다른 위험이므로 전·후·좌·우 방향별 힘과 모멘트를 각각 확인해야 합니다.
    • 복합운송은 각 운송 구간 중 더 불리한 조건을 고려해야 합니다.
    5. Cubestow의 현재 반영 범위
    • 경계·충돌·중량·지지·미배치 검증과 3축 무게중심, 중심 편차, 수직 무게중심, 50% 길이 구간의 최대 질량 집중도를 제공합니다.
    • 상부 허용하중이 입력된 제품은 상부 화물의 누적하중을 검사하고, 미입력 제품은 미검증으로 구분합니다.
    • 해상·복합·육상 운송별로 높은 적층, 측면 간극, 문측 노출과 원통 구름 위험을 선별합니다.
    • 래싱 강도·경로·수량은 화물과 현장 조건에 따라 달라지므로 자동 산출하지 않습니다.
    • 따라서 현재 결과는 CTU Code 기반 사전 검토 자료이며 적합성 인증이나 현장 승인을 대신하지 않습니다.
    현장 책임자 확인실제 적입 전 최신 CTU Code, 운송 구간별 규정, 컨테이너 제작사와 고정재 제조사 지침을 확인하세요.
